    Data tools (team only)

    Add new data without touching code. Works for preview; then save the files into the project folder.
    1. GeoTIFF (.tif)
    Select the yearly GeoTIFFs exported from GEE (file name must contain the year, e.g. ntl_2025.tif). The globe image and the stats are built automatically. PNG files also work.
    2. Stats CSV (optional)
    Stats are computed from the TIFs already. Load a GEE CSV only to override them (columns: name, lat, lng, y2016 … ; a row named GLOBAL sets the global line).
    3. Save

    Put data.json in data/ and the PNGs in images/.
